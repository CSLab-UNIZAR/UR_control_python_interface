# UR_CONTROL Python requirements (Windows and Linux, Python 3.10 - 3.14)
#
# Windows: setup.bat (or setup.ps1)   Linux: ./setup.sh
# Both create .venv and install this file. Manual: python -m pip install -r requirements.txt
#
# Only direct dependencies are listed; pip resolves the rest. Versions are the
# ones UR_CONTROL was validated with on the Campero (Python 3.10 - 3.13).
# Python 3.14 (e.g. Ubuntu 26.04) needs the first numpy/scipy releases with
# 3.14 wheels; that combination is tested offline only.
